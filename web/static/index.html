Đang thu thập và phân tích dữ liệu website...

1. Kiểm tra kỹ thuật (HTTPS, robots.txt, sitemap, canonical, chuyển hướng)...
2. Phân tích nội dung cơ bản (Tiêu đề, mô tả, cây H1-H6, mật độ liên kết, ảnh)...
3. Đọc dữ liệu có cấu trúc Schema (JSON-LD)...
4. Đo lường tốc độ trải nghiệm thực tế (Google Core Web Vitals)...
